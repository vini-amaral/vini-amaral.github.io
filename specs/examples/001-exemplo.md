# Exemplo: Seção "Meus Projetos"

> Este arquivo é só um exemplo de referência — apague quando não precisar
> mais dele, ou deixe como modelo.

## Objetivo
Adicionar uma seção na home mostrando meus projetos mais recentes, para que
visitantes vejam rapidamente meu trabalho e cliquem para ver mais.

## Requisitos
- Mostrar de 3 a 6 projetos em cards (imagem, título, descrição curta)
- Cada card tem link para o repositório no GitHub e, se existir, para o
  site do projeto
- Cards em grid: 3 colunas no desktop, 1 coluna no mobile

## Critérios de pronto
- [ ] Seção aparece na home logo abaixo do hero
- [ ] Layout se adapta corretamente em mobile (testar em ~400px de largura)
- [ ] Todos os links abrem em nova aba

## Fora de escopo (opcional)
- Filtro por tecnologia (fica para uma spec futura, se necessário)
- Página dedicada por projeto
