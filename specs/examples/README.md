# `specs/` — Especificações das funcionalidades

Antes de construir algo não trivial no site, escreva um arquivo curto aqui
descrevendo o quê e por quê — depois é só pedir para implementar a partir
dele.

## Como usar

1. Copie [`TEMPLATE.md`](TEMPLATE.md) para um novo arquivo:
   `NNN-nome-curto.md` (numeração sequencial: `001-`, `002-`...).
2. Preencha as 4 seções (leva 5 minutos, não precisa ser perfeito).
3. Peça para implementar: *"implemente a spec 002-galeria-projetos"*.

Para ajustes pequenos (typo, cor de botão, texto), não precisa de spec —
só peça direto.
