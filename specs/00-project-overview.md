# Project Overview

## Project

- **Name:** `vini-amaral.github.io`
- **Type:** Personal professional developer portfolio
- **Hosting:** GitHub Pages
- **Primary language:** Portuguese (Brazil), unless content specification says otherwise
- **Audience:** recruiters, technical leaders, engineering managers, clients and other developers
- **Primary objective:** communicate professional positioning, technical capability, selected projects and experience clearly and credibly.

## Core principle

The website is a **professional developer portfolio first** and a visual experiment second.

The Noir Comics aesthetic must support hierarchy, readability, personality and memorability. It must never introduce fictional narratives, fake achievements, invented project details or decorative elements that obscure professional information.

## Success criteria

1. A visitor understands who Vinicius is and what he does within the first viewport.
2. A visitor can reach projects, experience, skills and contact information quickly.
3. Every project communicates problem, solution, role, technology and evidence.
4. The website works well on desktop and mobile.
5. Light and dark themes remain accessible and coherent.
6. The site can be maintained by changing structured content rather than rewriting presentation components.
7. The generated application can be deployed as a static Angular application on GitHub Pages.

## Non-goals

- Do not invent professional achievements, metrics, clients, employers, projects or technologies.
- Do not turn the portfolio into a comic-book story or role-playing experience.
- Do not add unnecessary animations merely because the visual reference is Noir Comics.
- Do not introduce a backend unless a future requirement explicitly demands it.
